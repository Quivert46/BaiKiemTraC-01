# BaiKiemTraC-01
I. Phần lý thuyết và câu hỏi ngắn 
1.
- Values Type (Kiểu giá trị): lưu trực tiếp giá trị trên stack khi là biến cục bộ, hành động gán biến chính là sao chép giá trị và 2 biến thường độc lập với nhau. VD: int, double, bool, struct...
- Reference Type (Kiểu tham chiếu): lưu tham chiếu đến đối tượng thường nằm trên Heap, hành động gán biến chính là sao chép tham chiếu và 2 biến có thể cùng trỏ 1 đối tượng. VD: class, array, string...
2.
- Thuộc tính init chỉ gán trong quá trình khởi tạo đối tượng 
- Giá trị không thể thay đổi sau khi khởi tạo
- Phù hợp với dữ liệu cố định

* Trường hợp thực tế:
class Acc
{
  public int AccNumber { get; init; }
  public string Owner { get; init; }
  public decimal Balance { get; init; }
}

Acc acc = new Acc
{
  AccNumber = 77777;
  Owner = "Nguyen Van A";
  Balance = 500000;
}

acc.Balance = 800000; // Có thể thay đổi
acc.AccNum = 88888; // Không thể thay đổi
3.
- virtual cho phép phương thức của lớp cha được lớp con ghi đè
- override cung cấp cách triển khai mới cho phương thức virtual
4.
- Bởi static nghĩa là thành phần đó thuộc về toàn bộ class và được truy xuất qua tên class chứ không thuộc về từng đối tượng riêng biệt
